# Toward Summer-Long Exposure to Contiguous Heatwaves in Europe: a Multi-Model Analysis
Lou Mandonnet, Aglaé Jézéquel, Fabio D'Andrea, Yoann Robin, Améline Vallet
Submitted to Earth's Future

Users can either download data of the three datasets (ERA5, GHS-POP, FPOP) and preprocess data or can download the preprocessed dataset directly on Zenodo, where part of the output data is also available:

- Preprocessed data including population data, ERA5 output data is available here: [https://doi.org/10.5281/zenodo.22832182](https://doi.org/10.5281/zenodo.22832182)
- CORDEX output data for the 9 selected model is available here: [https://doi.org/10.5281/zenodo.22834501](https://doi.org/10.5281/zenodo.22834501)


Raw ERA5 data can be accessed at: [https://cds.climate.copernicus.eu/cdsapp#!/dataset/reanalysis-era5-single-levels](https://cds.climate.copernicus.eu/cdsapp#!/dataset/reanalysis-era5-single-levels) 

Raw GHS-POP data can be accessed at: [https://human-settlement.emergency.copernicus.eu/download.php?ds=pop](https://human-settlement.emergency.copernicus.eu/download.php?ds=pop)

Raw FPOP data can be accessed at: [https://doi.org/10.5281/zenodo.10716877](https://doi.org/10.5281/zenodo.10716877) 

CORDEX data can be accessed at: [https://cordex.org/data-access/cordex-cmip5-data/how-to-access-cordex-cmip5-data/](https://cordex.org/data-access/cordex-cmip5-data/how-to-access-cordex-cmip5-data/ )

Users will also have to set correct folder locations in the scripts. Some of the scripts have been written for computation on the ESPRI cluster.
